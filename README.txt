Como correr la UI:

- Abra el "mock server de prueba.py"

- Abra el "MonopolyGodotClient.exe"

- Corra el programa de python ya sea en visual o idle

- Comience poniendo los mensajes en la terminal de python:

jugador/1/activar
jugador/2/activar

- Puede agregar hasta jugador/4/activar

- Puede desactivar jugadores con:

jugador/#/desactivar

- Puede moverlos con:

jugador/#/mover/casilla/x

Mueve al jugador a la casilla numero x, aun no puede aumentar o disminuir la cantidad de casillas

Cuando termine, simplemente cierre los programas
